# Projects

## Project Grandmaster (SCARA robot for Go)
- **Context:** Year 3 individual project
- **Summary:** 3-DOF SCARA arm that plays Go as a physical opponent
- **Tech / tools:** SolidWorks, 3D printing, Arduino (C++), Python (Tkinter), Denavit-Hartenberg kinematics
- **Result:** 100% pick-and-place success; 2 mm accuracy target not met due to belt-drive backlash
- **Link:** <https://github.com/umbelinapia/GoPlayingRobot.git>

## Toothpick (autonomous cylinder pick system)
- **Context:** group coursework (3 people)
- **Summary:** 3-DOF gantry robot with an AI camera that finds and sorts cylinders
- **My part:** mechanical structure and computer-vision pipeline
- **Tech / tools:** ESP32-S3, stepper/servo motors, Gaussian blur, Hough circle detection
- **Result:** 100% success over 3 runs; 1 of 3 teams (out of 13) to complete the task; cycle time (~1 min) missed the <10 s target
- **Link:** <https://github.com/umbelinapia/ToothPick.git>
